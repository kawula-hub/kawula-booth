Kebijakan Privasi

Terakhir diperbarui: 27 September 2026

Data yang diproses

Kawula Booth mengambil foto, GIF, dan video pendek tamu selama sesi photobooth. Semua file disimpan di komputer booth. Aplikasi juga mencatat data transaksi sesi (metode pembayaran dan nominal) untuk laporan kas pemilik booth.

Akses Google Drive

Aplikasi meminta izin Google Drive dengan cakupan drive.file, sehingga aplikasi hanya dapat melihat dan mengelola file serta folder yang dibuatnya sendiri. Aplikasi tidak dapat membaca file lain di Google Drive Anda. Izin ini dipakai semata-mata untuk mengunggah hasil foto sesi ke folder "Kawula Booth" di Google Drive akun pemilik booth.

Penyimpanan & keamanan

Token login Google disimpan terenkripsi di komputer booth (Windows DPAPI) dan tidak dikirim ke server mana pun selain Google. Kawula Booth tidak menjual, membagikan, atau mengirim data ke pihak ketiga. Penggunaan data dari Google API mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use.

Penghapusan data

Pemilik booth dapat menghapus sesi foto dari menu Galeri aplikasi, dan dapat mencabut akses aplikasi kapan saja melalui tombol "Putuskan" di aplikasi atau di pengaturan akun Google. Tamu yang ingin fotonya dihapus dapat menghubungi pemilik booth.
